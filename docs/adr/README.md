# Architecture Decision Records

Each significant decision gets a short record: `NNNN-title.md` with its status, context, decision, the owner's
decisions, alternatives and consequences, as smaltdb's records have.

**One numbering for all smalt ADRs** (owner's rule, 2026-11-09): records in every smalt repository share one sequence,
continuing smaltdb's ([0001–0022](https://github.com/stenhoor/smaltdb/tree/main/docs/adr)). A new record takes the next
number after the highest in any repository, open PRs included.
